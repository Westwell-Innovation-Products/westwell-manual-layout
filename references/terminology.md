# FMS 已确认术语

这是 FMS 专业词表，按相关内容使用，不机械套到无关行业。用户对当前任务的明确术语要求优先。实际界面按钮文字保持截图原样，正文解释按下表统一。

| 中文或概念 | 英文/写法 |
| --- | --- |
| 上岸桥 VPB | in-vpb |
| 下岸桥 VPB | out-vpb |
| 转场 | relocating |
| 车辆 | AT；复数 ATs，人工集卡仍区分为 MT |
| 路径规划 | path planning |
| 空箱区 | fork park |
| 任务派发 | dispatch |
| 调度 | schedule |
| 指令 | instruction |
| 死锁 | deadlock |
| 船舶 | vessel |
| 锁站 | Twistlock Station（TS） |
| 灵活锁站 | SSQ |
| 禁行区 | 英文标题、正文、目录及图注使用 UA |
| 缓停 | Stop；英文解释 controlled stop |
| 紧停 | Estop；英文解释 emergency stop |

- `path palnning` 是已确认的拼写错误，正确为 `path planning`。
- 船舶编辑中不能修改的字段已确认为 **Vessel ID**，不是 Container ID。重新创建前需完成该船全部任务；具体操作仍以该产品原文为准。
- 不把 SSQ 扩展成所有 TS；固定锁站与 SSQ 要区分。
- 不把禁停区替换为 UA。禁停区为 no-stopping area，业务含义不同。
- Stop 与 Estop 的词表定义不等于重新定义界面的 Fleet Stop 功能。原系统按钮和行为不凭字符串包含关系做全局替换；有歧义先询问。
- 重派正文可以用 redispatch，对应界面名称仍保留 `Redo Task`；其他按钮如 `Abort Procedure`、`Update Task`、`Finish` 同理。
- 不确定的技术含义、缩写扩展或行为差异先向用户确认，不能用通顺英语掩盖业务不确定性。
- 本 FMS 项目的称呼为 POF；该替换仅用于此项目，不把所有“英国”字样全局改成 POF。
