# 交付检查清单

根据改动范围选择检查项目；简单颜色修改不必重复全套内容重写。

## 视觉与结构

- [ ] 完整新手册包含独立首页封面并置于目录前；产品名、项目、语言、版本日期来自本次输入，不沿用样例值。局部修改不无故重建封面。
- [ ] 正文/主要标题黑色，强调色墨子蓝；截图和正式 Logo 未被改色。
- [ ] 目录一级蓝、二级黑；侧栏和扉页导航一致；英文 Chapter N 未拆行或覆盖后一列。
- [ ] 扉页纯白、内容块整体居中且块内左对齐。
- [ ] 入口卡片 `#FAFAFA`、4px 圆角、无边框。
- [ ] 注意事项/Tips 浅色底、圆角，仅左侧 3px `#2CCCD3`；图标分工正确。
- [ ] 先操作说明后图，图注在下且居中；步骤与截图对应。
- [ ] 真正动作才编号；说明页不被强行加入入口/步骤；功能页顺序正确。
- [ ] 小标题无冒号；卡片正文无重复“注意：”等标签；说明不是灰色斜体小字。

## 内容与引用

- [ ] 未遗漏原有文字、截图、Tips、风险说明和跨章节引用；授权删改有明确对应。
- [ ] 标题层级、步骤编号、目录页码和引用一致，所有内部链接有目标。
- [ ] 专业术语已按本次语言和词表核对；保留实际按钮名称；不确定项已确认。
- [ ] 用户只授权局部修改时，没有顺带改其他版本、其他输出或业务逻辑。

## 实际渲染

- [ ] 等待字体和图片加载完成后检查；正文不能越过页脚，列间不能相互覆盖。
- [ ] 至少抽查目录、扉页、最密集功能页、提示卡片和表格；改某组件时额外检查其代表页。
- [ ] 浏览器预览与打印媒体样式均正常；不能仅用 `overflow:hidden` 掩盖超页。
- [ ] PDF 请求：检查实际生成文件的页数、页面尺寸和内容，再渲染代表页检查，不以 HTML 截图代替 PDF 检查。
- [ ] HTML 请求：搜索、目录、原图放大等已有功能仍可用；需要手机阅读时检查横向溢出。

## 交付说明

- [ ] 给出正确产物链接，简述修改内容和验证结果。
- [ ] 记录本次选定样式/例外。后续只维护 Skill 中的固定规范；调用 Prompt 不复制一套规则。
